Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.py` (Python 3, pure stdlib, deterministic, no network) writes one
roast line — 134 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My robot vacuum mapped my whole house in a day, then got stuck on the same rug every day since — genius cartographer, terrible driver.

The roast turns on a double contrast: a machine smart enough to map the
whole house in a day, dumb enough to lose to the same rug every day since —
and the kicker names both halves in four words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
